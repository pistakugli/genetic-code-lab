## Artifact Hygiene Rule

The root `benchmarks/` directory is legacy mixed-use. It contains both:

- release-style benchmark artifacts generated by `scripts/benchmark-*.ts`
- scratch experiment artifacts generated by `scratch/*`

Release benchmark scripts now write under `benchmarks/release/<lane>/<variant>/report.{json,md}` by default. Scratch scripts now write under `benchmarks/scratch/<lane>/` for data/formulas and `artifacts/scratch/<lane>/` for reports/plots by default. The generating command still matters.

Smoke and wide commands are now separated by variant directories for the patched release scripts. Root-level artifacts are legacy and must not be treated as current evidence.

Legacy report/log folders are treated as historical repair input until a current verifier reruns them:

| Legacy path | Current status | Audit |
|---|---|---|
| `REPORTS/` | historical notes only | `docs/legacy-artifact-audit.md` |
| `audit/` | mixed old experiments, invalid JSON, failed/OOM diagnostics, and forensic traces | `docs/legacy-artifact-audit.md` |
| `.gemini/antigravity` | no files found in this repo during the 2026-05-22 audit | `docs/legacy-artifact-audit.md` |
| root `output_*.log` | old async-agent/co-evolution diagnostics only | `docs/legacy-artifact-audit.md` |

Scratch-generated benchmark files must be treated as experimental unless a
separate release gate promotes them. Known scratch-written artifacts now use:

| Artifact pattern | Writers | Status |
|---|---|---|
| `benchmarks/scratch/concrete/concrete_nn_*.csv` | `scratch/train_concrete_network.py` | scratch dataset |
| `benchmarks/scratch/concrete/concrete_v2_seed*.txt` | `scratch/evolve_concrete_ensemble.py` | scratch formulas |
| `benchmarks/scratch/california/california_nn_*.csv` | `scratch/train_california_network.py` | scratch dataset |
| `benchmarks/scratch/california/california_surrogate_seed*.txt` | `scratch/evolve_california_surrogate.ts` / ensemble scripts | scratch formulas |
| `benchmarks/scratch/complex/complex_nn_*.csv` | `scratch/train_complex_network.py` | scratch dataset |
| `benchmarks/scratch/pytorch-neuron/nn_activations.csv`, `nn_validation_activations.csv`, `pytorch_ground_truth.csv` | `scratch/extract_neural_activations.py` | scratch explainability data |
| `benchmarks/scratch/llm/llm_activations.csv` | `scratch/extract_llm_activations.py` | scratch explainability data |
| `benchmarks/scratch/extrapolation/extrapolate_*.csv`, `best_trig_expression.txt`, `best_rational_expression.txt` | extrapolation scratch scripts | scratch extrapolation lane |

Scratch can contain valuable experiments. It must not silently overwrite or
redefine release evidence. Current scratch readers may fall back to legacy root
files only so old local datasets remain usable while the new layout is adopted.
