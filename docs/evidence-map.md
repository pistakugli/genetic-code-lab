## Artifact Hygiene Rule

The root `benchmarks/` directory is legacy mixed-use. It contains both:

- release-style benchmark artifacts generated by `scripts/benchmark-*.ts`
- scratch experiment artifacts generated by `scratch/*`

Release benchmark scripts now write under `benchmarks/release/<lane>/<variant>/report.{json,md}` by default. Scratch scripts now write under `benchmarks/scratch/<lane>/` for data/formulas and `artifacts/scratch/<lane>/` for reports/plots by default. The generating command still matters.

Smoke and wide commands are now separated by variant directories for the patched release scripts. Root-level artifacts are legacy and must not be treated as current evidence.

Legacy report/log folders are treated as historical repair input until a current verifier reruns them:

| Legacy path | Current status | Audit |
|---|---|---|
| `REPORTS/` | historical notes only | `docs/legacy-artifact-audit.md` |
| `audit/` | mixed old experiments, invalid JSON, failed/OOM diagnostics, and forensic traces | `docs/legacy-artifact-audit.md` |
| `.gemini/antigravity` | no files found in this repo during the 2026-05-22 audit | `docs/legacy-artifact-audit.md` |
| root `output_*.log` | old async-agent/co-evolution diagnostics only | `docs/legacy-artifact-audit.md` |

Scratch-generated benchmark files must be treated as experimental unless a
separate release gate promotes them. Known scratch-written artifacts now use:

| Artifact pattern | Writers | Status |

## Current Claim Boundaries

Project focus is governed first by `docs/gcl-north-star.md`, then by this
evidence map and `docs/nn-decompiler-roadmap.md`. If those files appear to
conflict, the stricter claim boundary wins.

Neural-decompiler terms such as "atom", "canonical structure", "canonical
signature", "surrogate", "non-identifiable", and "semantic hidden-neuron
identity" are governed by `docs/neural-decompiler-formalization.md`.

Allowed:

- GCL has a real, tested core engine and package surface.
- `gcl-hybrid` has earned a production-candidate status on the current wide symbolic-regression gate.
- Pure GCL now has a positive 8-task wide smoke result after the analytic scaffold fix, but broader public superiority still needs broader suites.
- GCL has controlled NN decompilation evidence: output-only symbolic distillation, activation-access tanh/ReLU circuit recovery, oracle-only 1D black-box ReLU circuit recovery, oracle-only deep folded 1D ReLU output-equivalent spline recovery, oracle-only deep folded 2D ReLU output-equivalent region-graph recovery including fixed, randomized, noisy, adaptive-adversarial noisy, compact-boundary, adaptive-budget, boundary-refined local-switching, subcell-boundary adaptive validation, and topology-boundary recovered-adjacency geometry gates, oracle-only deep folded 3D/4D ND output-equivalent affine-region sampler recovery including noisy adaptive-adversarial 3D/4D hard-profile recovery, adaptive-budget noisy deep-ND query reduction, recovered ND adjacency geometry beyond 2D, and a release-gated clean/noisy 5D recovered-adjacency geometry sweep, oracle-only 2D non-vertical ReLU kink-line recovery, oracle-only 3D non-vertical ReLU hyperplane stitching including a deterministic randomized seed sweep, clean 4D and randomized 4D/5D random-direction ND line-probe recovery, noisy/quantized 4D/5D ND line-probe recovery, generated adversarial noisy/quantized 4D/5D ND line-probe recovery, adaptive search-generated noisy/quantized 4D/5D ND line-probe recovery, and noisy/quantized 1D, 2D, and 3D black-box ReLU recovery including a non-degenerate randomized 3D seed sweep, a noisy 3D cancellation hard-case global refiner gate, a noisy 3D adversarial sweep with query-budget accounting, plus crossing-line, near-parallel, and near-collision hard cases in 2D.
- GCL has controlled active-subspace smooth FFN evidence for clean 256D/1024D, 4096D stress, and noisy 128D/256D rank-1 GELU/SwiGLU-style lanes; that lane remains benchmark-scoped active-subspace surrogate recovery, not real LLM decompilation.
- GCL now also has separate controlled GELU FFN structure-finder lanes that return explicit atoms for 96D single/two-channel teachers, a 32D clean rank-adaptive mixed-channel block where the true channel count is hidden, a 16D near-parallel epsilon family that keeps channel count and direction recovery stable down to `1e-4`, a cross-decomposition invariance gate where equivalent 3-atom and 6-atom hidden decompositions recover the same effective canonical atom count with close canonical signatures, a formalization negative-case gate that prevents selected unsupported structure promotions while also failing if a measurable weak third channel is collapsed away by minimum-model bias, a controlled noisy/quantized mixed GELU family that recovers balanced, near-parallel, and weak-but-resolvable three-channel structures with separate structure and prediction-sanity gates, controlled clean/noisy mixed SwiGLU value/gate structure lanes, controlled shared-gate/cancellation-heavy SwiGLU canonicalization into the minimal equivalent pair, and a provenance-mode verifier that maps recovered atoms to exact source ids/layers/indices/groups when a source-neuron manifest or equivalent instrumentation is provided. This is the correct direction for neuron/block structure recovery, but it is not yet full GPT-2 FFN extraction, arbitrary cancellation-heavy mixed-block recovery, arbitrary 3072-channel recovery, or output-only original-neuron identity.

This is instrumented source mapping, not output-only identity.
- GCL has a local live GPT-2 reader that loads the real model, hooks MLP activations, runs causal ablations, and records disjoint negative-control families. This is a real oracle-instrumentation layer, not a standalone claim that GCL automatically understands GPT-2.
- GCL has a first live GPT-2 fact-circuit graph finder that scans configured factual prompts, selects MLP graph nodes, emits token/neuron/target graph artifacts, and validates joint graph ablation above graph-level controls plus paraphrase, wrong-answer, negative-fact, and unrelated-logit hardening for the current 50-valid-fact gate. This is benchmark-scoped MLP graph discovery and Stage-I hardening, not attention-head/path recovery, full GPT-2 FFN extraction, arbitrary LLM understanding, output-only original-neuron identity, or broad SOTA.
- GCL has separate live GPT-2 attention-path, combined attention+MLP graph, and ordered residual path gates. The attention-path gate validates selected heads through real `c_proj` path ablations; the combined gate builds one token/head/neuron/target union graph and validates it through simultaneous attention+MLP ablation above combined controls; the ordered residual path gate verifies attention->residual->MLP activation dependency above full-control path interventions while preserving target-logit causal effectiveness. This is benchmark-scoped graph/path evidence for the configured factual prompt set, not exhaustive full-circuit recovery, arbitrary LLM understanding, output-only original-neuron identity, or broad SOTA.
