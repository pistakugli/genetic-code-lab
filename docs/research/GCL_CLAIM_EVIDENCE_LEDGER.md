# GCL claim–evidence ledger

**Audit cutoff:** 2026-10-30. The ledger distinguishes direct source support from measured outcomes and from the claim that the evidence can justify. Existing reports are linked rather than altered.

| Claim | Implementation witness | Experimental witness | Status / exact boundary |
|---|---|---|---|
| GCL can load and instrument GPT-2 | [`gpt2_internal_trace.py`](../../tools/llm_reader/gpt2_internal_trace.py), `GPT2TraceCapture`, local-only model loading | [All-50 trace report](../../benchmarks/release/nn-live-gpt2-autoregressive-causal-trace/all-50/report.json); [trace verifier](../../tools/llm_reader/verify_gpt2_autoregressive_causal_trace.py) | **Established for the recorded GPT-2 setup.** White-box/instrumented access, not black-box recovery. |
| The trace captures a full transformer computation | Trace hooks cover residual, attention/head writes, MLP, norm and logits | 50 cases / 600 steps recorded; verifier checks greedy replay and raw tensors | **Overbroad as worded.** It captures the listed boundaries and contributions, not every internal quantity (e.g. attention probability matrices are absent), and not a complete semantic decomposition. |
| Residual arithmetic reconstructs exactly | Residual block accounting in the trace | Five-case report records max error 0; all-50 report records max about `3.05e-5` | **Exact only in the five-case measurement.** All-50 is numerically close but not bitwise exact. |
| GCL reproduces actual next-token predictions | Autoregressive baseline recomputation in `run_autoregressive_case` | 50/50 cases; 600/600 greedy token IDs replayed | **Established for the frozen inputs/model/config and reported steps.** Generated sequence is capped at 12 tokens and does not establish complete answer generation. |
| GCL explains actual model predictions, not just fixed target tokens | Per-step records contain exact context, logits, top candidates and intervention effects | 600 actual greedy prediction steps and explanations | **Partially supported.** Evidence is about the baseline greedy token at that context; first-order attributions and text descriptions do not establish exhaustive causal explanation. |
| Every factual answer target is what GPT-2 predicts | Source fact target is recorded separately from greedy token | In initial contexts, source target is greedy in 7/50; top-five in 23/50 | **False.** The trace properly distinguishes target likelihood from emitted next token. |
| Discovered paths causally influence outputs | Hook-based path/group/component ablations and restoration | Measurable influence in 44/50 cases; path restoration; in transfer, positive answer-likelihood drop on 44/45 facts | **Established as context-conditional influence for these measurements.** Does not prove necessity, specificity, semantics or sufficiency. |
| Paths are necessary for the factual predictions | Frozen-path removal in the original context | Strict correct-greedy change for 3/45 facts; likelihood drop for 44/45 | **Not generally established.** Likelihood influence must not be reported as strict behavioral necessity. |
| Paths are sufficient to produce the answer | Donor-path transfer and answer-sequence likelihood scoring | 985/1,488 directions improve donor-answer likelihood | **Not established.** A likelihood shift is not exact output reproduction or full-circuit sufficiency. |
| Paths transfer factual information between prompts | Exact fixed-text position alignment and directional patching in `gpt2_counterfactual_transfer.py` | 1,488/1,488 transfers applied; donor-answer likelihood improves in 985 directions | **Established as an intervention and directional effect in a subset.** Positive effect is not proof of complete information transfer. |
| Cross-factual transfer is a new causal operator | Same implementation above | IIT/causal abstraction/activation patching are prior art [R11, R12] | **Unsupported.** The operator is established; GCL may contribute a specific paired evaluation. |
| GCL establishes path specificity against random controls | Matched-control construction and frozen 20% magnitude threshold | All-50 strict specificity passes 0/50; transfer has 38 valid comparisons, 37 pass; 1,450/1,488 directions lack valid matches | **Not established globally.** State the 37/38 control-valid subset, not a blanket claim. |
| A specific path is more selective than any active random neuron | Five-case intervention report includes random-active-neuron matched comparison | Random active neuron has larger ablation effect than selected path for Italy | **Counterexample exists.** The selected path is not shown to win every comparison. |
| Component interactions reveal redundancy/synergy | Group and individual removals; interaction = combined effect minus individual sum | 600 interactions recorded; report categories are 427 approximately additive, 85 subadditive, 88 superadditive | **Interaction is measured.** The labels do not by themselves identify a unique redundant or synergistic mechanism. |
| Discovered paths are robust to paraphrasing | OOD replay of frozen paths | 13/30 OOD paraphrase prompts pass across 2/5 cases; standard comparison 30/30 | **Fails this OOD pilot.** No broad robustness claim is supported. |
| GCL performs all-pairs counterfactual transfer on the eligible factual set | Pair inventory uses exact template/token alignment; no result selection by observed effect | 45 eligible facts, 744 unordered pairs, 1,488 directions; five passed facts excluded for no repeated template family | **Established for this source artifact.** It is not all 50 passed facts and not all source rows. |
| Transfer specificity has a positive statistical result | Endpoint-cluster bootstrap and BH correction in runner/verifier | Country-capital valid subset: 38 directions, 37 pass; mean path-minus-control `0.2585`, CI `[0.2157,0.3035]`, `q=0.000637` | **Supported only in that small valid-control subset.** 1,444/1,482 country-capital directions are unverified for magnitude-matched specificity; small relation families are descriptive. |
| GCL has independently verified raw activation archives | Trace/transfer verifier code checks hashes, alignments, statistics, raw records and optional model replay | Transfer verifier reports replay of all 1,488 directions in its frozen report | **Strong verification pipeline exists.** This audit inspected the verifier but did not rerun it; “independent” means independent checks/recomputation within the repository, not a separately authored model/solver. |
| GCL is robust across model families | Adapter registry contains four families | Separate model-family path artifacts exist; current audit did not replay all families | **Not established end-to-end.** Adapter support is narrower than feature/experiment parity. |
| GCL has OOD circuit validation | OOD template generator and report verifier | OOD result records 13/30 and overall failure | **A capability exists to test it; robustness result fails.** |
| GCL is a black-box GPT-2 neural decompiler | GPT-2 trace reads local weights and hooks | 50-case trace/transfer | **False.** Those are instrumented open-model experiments. |
| GCL is a black-box SwiGLU function decompiler | Oracle solver queries scalar outputs; source truth is reserved for post-hoc alignment | Two selected cases pass; randomized strict 16-atom court passes 1/6 | **Narrow selected-function recovery is demonstrated.** The tested solver receives the SwiGLU family and atom-count/rank prior; oracle metadata exposes unit count; this is not full-model decompilation. |
| The SwiGLU structure is uniquely identifiable | `identifiability_verdict`, canonicalization and source-alignment diagnostics | Synthetic verdict tests; post-hoc paired-atom checks in real-source reports | **General uniqueness unsupported.** Equivalent parameterizations, cancellation, weak channels and alternative decompositions remain relevant. |
| The randomized cold-start result establishes robust recovery | Strict court uses randomized layer/family/mode strata and frozen thresholds | 1/6 pass, 5/6 fail; 7,932,316 raw calls | **Refuted by the current strict result.** A selected 2/2 pass must be presented separately and not generalized. |
| GCL fully reconstructs a trained neural network | No corresponding full-layer/model source or acceptance artifact was found in the audited implementation | Current GPT-2 analyses use selected paths; black-box court targets selected unit sums | **Unsupported.** Do not describe the current system as complete neural decompilation. |
| The exact GCL 744-pair protocol is unprecedented | Local protocol/artifacts can be verified; public prior art searched through cutoff | R11/R12 establish the intervention family; no matching 744-pair protocol identified in reviewed sources | **Unknown beyond search scope.** Safe statement: no exact match was found in the cited sources; do not claim historical first. |
| GCL has a novel general extraction algorithm | Solver code and selected/randomized artifacts | Jagielski et al. already give direct extraction for a restricted ReLU class; current GCL court has disclosed priors and mixed results | **Not established.** Distinct target family/application is plausible; algorithmic novelty requires formal comparison and stronger blind evaluation. |
